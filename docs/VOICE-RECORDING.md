# Voice recording portal

Private studio for recording Bosnian vocabulary and dialogue voice-overs. Clips upload to S3 and play on the lesson site when learners tap a word or dialogue line.

## Roles

Four voice talents (shared password):

| ID | Label | Gender |
|----|-------|--------|
| `female-1` | Female voice 1 | female |
| `female-2` | Female voice 2 | female |
| `male-1` | Male voice 1 | male |
| `male-2` | Male voice 2 | male |

Dialogue lines prefer matching gender (Ana/Amira → female, Emir → male). Vocab and narrator/shopkeeper lines accept any voice. Edit display names in [`content/audio/voice-profiles.json`](../content/audio/voice-profiles.json).

## Clip IDs

Stable keys (do not renumber dialogue lines casually):

- Vocab: `b{book}-d{day}-vocab-{slug}`
- Dialogue: `b{book}-d{day}-dialogue-{index}`

Catalog is generated by `node scripts/build-audio-clips.cjs` (also via `sync-content`).

S3 object key: `clips/{clipId}`  
Public URL: `{AUDIO_CLOUDFRONT}/clips/{clipId}`

## iPhone recording

1. Open the recorder CloudFront URL in **Safari**
2. Enter the shared password: **`GornjiVakuf`**
3. Choose your voice profile
4. Open a lesson → tap a clip → **Start** → allow microphone → **Stop** → preview → **Upload**

Safari on iOS 14.3+ supports `MediaRecorder` (`audio/mp4`).

## Local development

```bash
# regenerate clips.json into frontend / recorder / backend
node scripts/sync-content.cjs

# recorder UI (needs a running audio API)
cd recorder
cp .env.example .env   # set VITE_AUDIO_API_URL + VITE_AUDIO_PUBLIC_BASE
npm install
npm run dev
```

Lesson site playback:

```bash
# frontend/.env
REACT_APP_AUDIO_BASE_URL=https://<audio-cloudfront-domain>
```

## API

| Method | Path | Auth | Purpose |
|--------|------|------|---------|
| POST | `/audio/login` | password body | Issue bearer token |
| GET | `/audio/clips` | bearer | List clips + recording status |
| GET | `/audio/voices` | bearer | Voice profiles |
| POST | `/audio/upload-url` | bearer | Presigned S3 PUT |
| POST | `/audio/complete` | bearer | Mark clip recorded in DynamoDB |
