# Voice recording portal

Private studio for recording Bosnian vocabulary and dialogue voice-overs. Clips upload to S3 and play on the lesson site when learners tap a word or dialogue line.

## Roles (exclusive queues)

Four voice talents share one password. Each person **only sees their own assigned lines**:

| ID | Label | Owns |
|----|-------|------|
| `female-1` | Female 1 — vocab, Ana, narrator | **All vocabulary**, Ana dialogue, Narrator |
| `male-1` | Male 1 — Emir | Emir dialogue |
| `female-2` | Female 2 — Amira | Amira dialogue |
| `male-2` | Male 2 — shopkeeper & Mrvica | Shopkeeper + Mrvica (cat) — always the same voice |

Side characters (shopkeeper, cat, narrator) are pinned to one talent so deliveries stay consistent. Edit assignments in [`content/audio/speaker-genders.json`](../content/audio/speaker-genders.json) and labels in [`content/audio/voice-profiles.json`](../content/audio/voice-profiles.json).

## Workflow

1. Open the recorder CloudFront URL in **Safari** (iPhone) or Chrome/Firefox (desktop)
2. Enter the shared password: **`GornjiVakuf`**
3. Choose which voice you are recording for
4. Open a lesson → tap a clip from **My missing** → **Record** → allow microphone → **Stop**
5. **Clip beginning & end** with the trim sliders
6. **Play back** the trimmed take
7. **Accept this take?** → confirm → upload to S3

Safari on iOS 14.3+ supports `MediaRecorder` (`audio/mp4`). Accepted takes are trimmed in-browser and uploaded as WAV.

## Clip IDs

Stable keys (do not renumber dialogue lines casually):

- Vocab: `b{book}-d{day}-vocab-{slug}`
- Dialogue: `b{book}-d{day}-dialogue-{index}`

Catalog is generated by `node scripts/build-audio-clips.cjs` (also via `sync-content`). Each clip has an `assignedVoiceId`.

S3 object key: `clips/{clipId}`  
Public URL: `{AUDIO_CLOUDFRONT}/clips/{clipId}`

## Local development

```bash
# regenerate clips.json into frontend / recorder / backend
node scripts/sync-content.cjs

# recorder UI (needs a running audio API)
cd recorder
cp .env.example .env   # set VITE_AUDIO_API_URL + VITE_AUDIO_PUBLIC_BASE
npm install
npm run dev
```

Lesson site playback:

```bash
# frontend/.env
REACT_APP_AUDIO_BASE_URL=https://<audio-cloudfront-domain>
```

## API

| Method | Path | Auth | Purpose |
|--------|------|------|---------|
| POST | `/audio/login` | password body | Issue bearer token |
| GET | `/audio/clips` | bearer | List clips + recording status (`?voiceId=` filters queue) |
| GET | `/audio/voices` | bearer | Voice profiles |
| POST | `/audio/upload-url` | bearer | Presigned S3 PUT (rejects wrong `voiceId` for clip) |
| POST | `/audio/complete` | bearer | Mark clip recorded in DynamoDB |
